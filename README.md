# To-Do List Application

A simple web-based To-Do List application developed to help users manage their daily tasks.
The application allows users to add and delete tasks through an easy-to-use interface.

## Technologies Used

- HTML
- CSS
- JavaScript
- Visual Studio Code
- Git
- GitHub
- GitHub Actions
- YAML
- GitHub Pages

## Key Features

- Add new tasks
- Delete existing tasks
- Input validation for empty tasks
- Enter-key support for adding tasks
- Simple and responsive user interface

## Process

1. The application was developed locally using HTML, CSS, and JavaScript.
2. The project was tested locally to ensure the features were working correctly.
3. Git was used for version control and meaningful commits were created.
4. The project was pushed to a GitHub repository.
5. GitHub Actions was configured for Continuous Integration.
6. A failed CI workflow was identified and the error was corrected.
7. The corrected project was pushed again and a successful CI workflow was obtained.
8. Finally, the application was deployed using GitHub Pages.

## What I Learned

Through this project, I learned how to develop a basic web application using HTML, CSS, and JavaScript.
I also learned how to use Git and GitHub for version control, configure GitHub Actions for CI, fix workflow errors, and deploy a web application using GitHub Pages.

## Conclusion

This project provided practical experience in web development, version control, Continuous Integration, and deployment.
It helped me understand the complete process of developing, testing, managing, and deploying a small web application.
